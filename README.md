# CareerForge AI

AI-powered CV screening and candidate ranking platform.

## Live Demo
https://careerforge-cnknphjy5awc78cgqffjmz.streamlit.app

## What it does
- Upload 100 CVs at once
- AI ranks candidates by match score
- Detects skills gaps and risk flags
- Generates custom interview questions

## Built with
Python | Streamlit | Groq API | NLP
